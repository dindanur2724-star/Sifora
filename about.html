Tentang SIFORA

Mengenal Sistem Informasi Fasilitas dan Pelaporan.

Apa Itu SIFORA?

SIFORA merupakan singkatan dari Sistem Informasi Fasilitas dan Pelaporan. Website ini dirancang sebagai sarana untuk membantu proses penyampaian laporan kerusakan fasilitas.

Melalui SIFORA, pengguna dapat mengisi informasi kerusakan, menentukan kategori fasilitas, menambahkan lokasi, memberikan deskripsi, dan mengunggah foto pendukung.

Tujuan Pengembangan

  • Mempermudah penyampaian informasi kerusakan fasilitas.
  • Membantu pemantauan status laporan.
  • Menyajikan informasi laporan secara terorganisasi.

Fitur Website

  • Login Admin dan Pelapor.
  • Dashboard pengelolaan laporan.
  • Formulir pelaporan kerusakan.
  • Upload foto fasilitas.
  • Pencarian dan filter laporan.

Teknologi yang Digunakan

Website SIFORA dibuat menggunakan HTML, CSS, dan JavaScript. Data demonstrasi disimpan sementara menggunakan localStorage pada browser sehingga tidak memerlukan database cloud.
